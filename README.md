# TRASHFORMERS - From Waste to Worth

React + React Router + Vite demo (no backend). The application source is in `src/App.jsx`.

## Run locally

1. Install Node.js (LTS).
2. Open a terminal in this `tf` folder.
3. Run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the local URL printed by Vite.

## Project notes

- The Marketplace contains exactly six sample listings. Their matching product-specific illustrations are stored locally in `public/images/`.
- The Marketplace illustrations are original SVG illustrations, not photographs of real creator submissions.
- The homepage workshop and festival highlight images still use Unsplash and need an internet connection.
- The Gallery page and navigation links have been removed.
- Dashboard Announcements have been removed; the rest of the Dashboard remains.
- Festival details can be edited in the `festivalInfo` object in `src/App.jsx`.
